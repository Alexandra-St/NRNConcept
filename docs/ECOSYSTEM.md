# Ecosystem

NRN is an independent concept exploring privacy education and informed communication choices. It is not an official Narayana product.

Privacy Lab provides category/topic discovery and practical guidance. Interactive Simulations add decision-based learning; Solution Finder explains contextual recommendations and limitations. All three are features within NRN.Web, sharing navigation, state conventions and visual components.

NRN.Telegram is a separate customer-oriented prototype with dashboard, local services/catalog/account data, help and learning links. The browser bot demo opens its preview without real authentication. Server-side Telegram validation exists, but authorized company integration, authoritative account data and service provisioning remain unfinished.

Education can end without a commercial recommendation. Narayana references provide public research context and external destinations; they do not imply commissioning, approval or deployment. See [implementation architecture](ARCHITECTURE.md) and [research traceability](RESEARCH_TO_PRODUCT.md).
