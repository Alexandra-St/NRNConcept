# Project Principles

This document defines how product decisions are made.

Concrete implementations of these principles are tracked in [`RESEARCH_TO_PRODUCT.md`](RESEARCH_TO_PRODUCT.md).

## 1. Speak human, not technical.

Technology should always be translated into everyday value.

Inspired by: Proton

---

## 2. Show values through experience.

Users should experience privacy rather than read about it.

Inspired by: Mullvad

---

## 3. Teach first. Sell second.

Education comes before product recommendation.

Inspired by: Silent.Link

---

## 4. Build trust through honesty.

Explain both strengths and limitations.

Inspired by: IVPN

---

## 5. Reduce unnecessary data.

The best protected data is data that never existed.

Inspired by: SimpleX

---

## 6. Make privacy invisible.

Privacy should feel effortless.

Inspired by: Signal

---

## 7. Balance privacy and usability.

Every decision has trade-offs.

Inspired by: Session
