# Original NRN project documentation

This archive preserves the project documentation from commit `687de16104bcab8107ff08a989d110d909837f1e`, before the recruiter portfolio changes. It includes every non-empty original Markdown document modified by that work, plus linked Markdown dependencies. Files retain their complete original bytes, wording, language, requirements and design decisions; nothing was translated or shortened in this snapshot.

Current documents outside this folder describe the audited implementation. Archived documents record how the concept was developed; they may contain historical plans, superseded screen lists, dated prices or test results, and company-oriented language that is not evidence of commissioning or approval. The archive is explicitly an independent project record, not a current implementation claim.

Original relative document links retain the mirrored repository structure. Original text/code path references and external sources retain their historical meaning. The Google Docs shortcut is not included, and no external document contents were fetched.

[Preservation manifest](manifest.json) records original paths, the baseline commit and SHA-256 checksums. Every archived file is checked byte-for-byte against that Git commit.
